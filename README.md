## توضیحات پروژه 📌
<!-- Project Description : استاندارد  -->
این پروژه یک افکت حرکتی مبتنی بر اسکرول کاربر (Scroll-Triggered Animation) را پیاده‌سازی می‌کند. با اسکرول کردن به سمت پایین، المنت‌ها بر اساس موقعیت مکانی خود نسبت به Viewport، به نوبت و به‌صورت متناوب از سمت چپ و راست با یک انیمیشن نرم وارد صفحه می‌شوند و در صورت اسکرول معکوس، خارج می‌گردند.

---
---


## ویژگی ها  
<!-- Features : استاندارد -->
-- انیمیشن ورود و خروج نرم با ترنزیشن CSS (Transform & Transitions)
- ورود تناوبی المنت‌ها از چپ و راست با استفاده از سلکتور :nth-of-type(even)
- محاسبه دقیق موقعیت مکانی هر المنت با تابع getBoundingClientRect
- کنترل تریگر فعال‌سازی بر اساس درصدی از ارتفاع صفحه (Trigger Point at 80% Viewport)
- کدنویسی تمیز، سبک و با جاوااسکریپت خالص بدون کتابخانه‌های جانبی

## Project Description 📌
<!-- Standard : Project Description  -->
This project demonstrates a scroll-triggered animation interface. As the user scrolls down the page, content boxes dynamically slide in from alternating directions (left and right) with smooth transitions once they reach a specific viewport threshold, and reverse smoothly when scrolled out of view.


---
---
---

## Features 🌏
<!-- Standard : features  -->
- Smooth sliding entrance and exit transitions using CSS transforms
- Alternating left and right slide-in directions via :nth-of-type(even)
- Real-time element position tracking using getBoundingClientRect
- Dynamic activation threshold set to 80% of window height
- Lightweight and modular implementation with vanilla JavaScript
